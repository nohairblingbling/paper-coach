# Deep-mode example

This example demonstrates stage boundaries and the one-answer-opportunity rule. It contains no real-paper facts.

## Stage 1 — Orientation

The coach reveals:

- title and identity;
- Abstract;
- central captions;
- only the terminology needed for this packet.

It asks 3–5 questions answerable from those materials. It does not mention an unseen Method, baseline, or result inside the questions.

## User reply

The reader answers one question and writes “I don't know” for the rest.

## Next coach response

The response has two visibly separated parts.

### Part A — Close Stage 1

```markdown
## Previous checkpoint
- Supported: [the user's correct portion]
- Completed/corrected: [all missing answers]
```

Every answer uses only the Stage 1 packet. The coach does not reveal a later experiment to retroactively grade an inference.

### Part B — Begin Stage 2

```markdown
## Paper Skeleton packet
[Introduction, Conclusion, section map, major figures/tables]

## Your one-pass questions
[problem–gap–contribution, visible evidence, limitations, one-sentence explanation]
```

## Later stages

The same pattern continues through:

1. Method/mechanism;
2. experimental evidence and critique;
3. an optional math, code, research, citation, or review track;
4. final teach-back.

At any stage the reader may say “pause”, “stay here”, “switch to quick”, or “skip this paper”.
