# Quick-mode example

This example demonstrates interaction shape, not answers to a real paper.

## User

```text
Use Paper Coach to quick-read this paper: example-paper.pdf
```

## Coach — response 1

```markdown
## Reading packet

### Paper identity
[title, authors, venue/version]

### Abstract — source text
[verbatim Abstract with locator]

### Key figures/tables
[caption and page locators]

### Selected Introduction/Conclusion excerpts
[only what is needed to make the four questions answerable]

## Your four questions

1. What did the authors try to accomplish?
2. What were the key elements of the approach?
3. What can you use yourself?
4. What other references do you want to follow?
```

The coach stops here.

## User

```text
I can answer question 1, but I am unsure about the others.
```

## Coach — response 2

```markdown
## Calibrated answers

1. Supported/corrected answer with evidence locator.
2. Completed answer with evidence locator.
3. Reader application / coach inference, clearly labeled.
4. Selective references with reasons.

## 30-second explanation
[concise explanation]

## Relevance decision
[why deeper reading is or is not worthwhile for the user's purpose]

## Most useful next action
[one action matched to the paper's actual claim]
```

The quick run is complete. The coach does not start another compulsory comprehension round.
