# Changelog

All notable changes to Paper Coach are documented here.

The project follows [Semantic Versioning](https://semver.org/).

## [1.0.2] - 2026-08-24

### Changed

- Removed the non-affiliation, sponsorship, and endorsement disclaimer while retaining the Andrew Ng CS230 source attribution and the distinction between lecture-derived methodology and Paper Coach's original extensions.

## [1.0.1] - 2026-08-24

### Changed

- Moved the Andrew Ng CS230 source attribution into the top of `SKILL.md` so registry pages such as skills.sh display it prominently.
- Clarified which reading principles come from the lecture and which interaction rules are original Paper Coach extensions.
- Added an explicit non-affiliation and non-endorsement statement to the registry-visible content.

## [1.0.0] - 2026-08-24

### Added

- Quick mode based on Andrew Ng's four paper-understanding questions.
- Progressive deep mode covering orientation, paper skeleton, mechanism, evidence, critique, and teach-back.
- One-answer-opportunity contract for every checkpoint.
- Strict local evidence boundary for questions and answer correction.
- Multilingual prompts and source/translation separation.
- Figure/caption honesty rules.
- Harness-neutral Agent Skills packaging.
- Optional Miyo + Poppler PDF structure/page mapper.
- English/Chinese README, examples, tests, and CI.
